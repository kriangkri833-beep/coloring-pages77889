# Coloring Pages Project

Shared workspace: ChatGPT (makes images) <-> Claude (builds pages, PDFs, listings).

## Folders
- prompts/            prompt text that worked (one .md per set)
- raw_from_chatgpt/   images saved from ChatGPT, untouched
- pages_final/        cleaned pages, ready to print / put in PDF
- notes/              research, decisions, listing text
- HANDOFF.md          running log: who did what, what is next

## Rules
- Never edit files in raw_from_chatgpt/ - copy to pages_final/ first.
- Update HANDOFF.md after every working session.
